How Security Works in This System
AES-128 (Fernet)
Encrypts sensitive data like phone, address, pincode using symmetric key encryption
SHA-256 Hash
Creates fixed-size digest for data integrity verification. One-way function.
PBKDF2-SHA256
Password hashing with 260,000 iterations + random salt for user passwords
CSRF Tokens
Random 256-bit tokens prevent cross-site request forgery attacks
